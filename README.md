# Static Site Generator Course On Boot.Dev

## Things I learned and accomplished 
- I learned what a static site generator is under the hood by building one myself.
- I generated HTML from Markdown files.
- I used a mix of Object Oriented and Functional programming.
- I wrote all my own tests using the unittest Python module.
- Fixed live bugs to deployment using Jujutsu and automatic rebasing.
- Discovered useful pattern of using a hashmap to return functions based on values for use in a list comprehension or map object.

## Tech stack
- Built using [Jusutsu (jj)](https://github.com/martinvonz/jj) Git backwards compatible version control system using change-based (stacked) workflow.
- Deployed with Github Pages.
- Built using Python and Markdown.
